Lire les résultats avec prudence

  • Complétude non garantie. Un extrait peut ne contenir qu'une partie des événements d'un bloc : les lignes fournies ne permettent pas de le vérifier.
  • Score non calibré. Le score n'est pas une probabilité. Un bloc est classé anomalie quand son score atteint le seuil, repère vertical sur la barre.
  • 50 premiers événements. Au-delà, les événements sont tronqués ; un événement hors vocabulaire est encodé comme inconnu.
  • Codes rares. Dans la séquence dépliée, un code est marqué « rare » s'il n'apparaît qu'une fois parmi les événements analysés du lot.
